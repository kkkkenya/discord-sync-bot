# Crux web: 20 November 2026

## Done

- **DeepSeek first (H1).** DeepSeek Flash is the first model on every plan in the desktop relay and in Crux's own AI work, with Gemini second. Photos and voice recordings still go to Gemini, since DeepSeek can't read them. Students on the old Gemini default move to DeepSeek; a student who picked Gemini in Settings keeps it. DeepSeek still stops at the monthly cap (`DEEPSEEK.monthlyCapUsd` in `server/defs.js`), and Gemini takes over after that. `server/ai-relay.js`, `server/ai.js`, `server/store.js`.
- **Every AI error handled (H3).** One table in `server/ai-errors.js` covers a wrong key, no credit, rate limits (with how long to wait), busy, timeouts, no connection, an answer cut off, a conversation too long, refused content, a bad setting and a garbled answer. The student sees one sentence and what to do. The raw error goes to the log with keys removed. When a model fails for a reason that isn't the student's, the next model answers and the page says so once ("DeepSeek is out of credit, so Gemini answered.").
- **Uploads with real-world names (H4).** Supabase Storage refused any file name with a curly quote, dash, accent or emoji (`InvalidKey`), and a name over 120 characters lost its extension and was turned away as the wrong type. The stored copy now gets a plain name; the hub still posts the real one. `server/hub-uploads.js`.
- **The PDF viewer (H2)** shows each page in its own shape. Pages that differed from page 1 were squashed. The page across the middle of the screen counts as the current page, so a jump to a tall page lands on it. `web/src/PdfViewer.jsx`.
- **The hub PC skips test files** named "Crux upload check …" (`pc/src/uploader/fromcrux.js`).
