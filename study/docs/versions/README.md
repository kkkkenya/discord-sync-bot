# Crux web: release notes

One file per release, named by its date (`YYYY.MM.DD.md`, Nairobi time). Crux web has no version number of its own;
`VERSION` in `server/store.js` is the data format, not the release.

Each file has the same parts:

- **Done**: what changed, with the commit.
- **To do**: decided but not built yet.
- **Scrapped**: tried or proposed, then dropped, and why.
- **Needs the owner**: steps only the owner can take (accounts, keys, Discord settings).

The desktop app keeps its own notes in the `crux` branch of the desktop repo, `docs/crux/versions/<version>.md`.
